# Lead Scoring Dashboard

Dashboard web desenvolvido para organizar, visualizar e analisar informações relacionadas a leads e oportunidades comerciais.

## Objetivo do projeto

O objetivo deste projeto é apresentar uma interface de apoio à análise de leads, permitindo visualizar informações comerciais de forma mais organizada e facilitar a identificação de oportunidades.

A solução foi criada como um projeto acadêmico e de portfólio, com foco na aplicação prática de conceitos de desenvolvimento web, organização visual de dados e construção de dashboards. A proposta é transformar informações de potenciais clientes em uma visão mais clara para apoiar processos de acompanhamento, priorização e tomada de decisão.

O projeto também representa uma aplicação de conhecimentos de negócio, análise comercial e tecnologia, áreas relacionadas à minha experiência profissional com e-commerce, métricas e performance de vendas.

## Funcionalidades

- Apresentação de indicadores relacionados a leads.
- Organização visual de informações comerciais.
- Exibição de dados em formato de dashboard.
- Interface voltada ao acompanhamento de oportunidades.
- Estrutura visual para apoiar a priorização de leads.
- Layout organizado para facilitar a leitura das informações.
- Aplicação acessível diretamente pelo navegador.

## Tecnologias utilizadas

- HTML5 para estrutura da aplicação.
- CSS3 para estilização e organização visual.
- JavaScript para comportamentos e interações.
- Git e GitHub para versionamento.
- GitHub Pages para publicação da aplicação.

## Como executar

1. Clone este repositório:

   ```bash
   git clone https://github.com/paulorsclima/lead-scoring-dashboard.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd lead-scoring-dashboard
   ```

3. Abra o arquivo `index.html` no navegador.

Também é possível utilizar o Live Server no Visual Studio Code para executar o projeto localmente.

## O que foi aprendido

Durante o desenvolvimento, foram praticados conceitos de estruturação de páginas web, organização de informações e criação de interfaces voltadas à análise de dados.

O projeto contribuiu para o aprendizado sobre HTML semântico, estilização com CSS e utilização de JavaScript para criar uma experiência mais dinâmica. Também foi possível exercitar a organização de elementos visuais, a apresentação de indicadores e a construção de uma interface adequada para acompanhamento comercial.

Outro aprendizado importante foi compreender como uma necessidade de negócio pode ser traduzida em uma solução visual. Em vez de apresentar dados de forma desorganizada, o dashboard busca destacar informações relevantes e facilitar a interpretação dos resultados.

A experiência também reforçou a importância do versionamento com Git, da documentação de projetos e da publicação de aplicações web por meio do GitHub Pages.
